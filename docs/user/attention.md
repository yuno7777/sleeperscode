# Attention

Open **Attention** from the sidebar to see work that needs a decision before it gets buried in a
thread list. The page groups active threads into **Needs you** and **Working**.

Needs-you items include provider approvals, user questions, failed runs, plans awaiting review,
and completed tasks that have no recorded verification. A completed task is not marked verified
just because the provider stopped. Add the checks you ran to its handoff summary to record that
evidence.

Select an item to open its thread. The page reads the local environment state and does not send
project or handoff content to another provider.
